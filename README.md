# تطبيق المنشية (Elmansheya Platform) 🏛️

المنصة الرقمية الموحدة لخدمات وتواصل أهالي قرية المنشية الكبرى.

## 🚀 الهيكل المعماري (Architecture)

1. **تطبيق المواطن (Frontend - Mobile):**
   - مبني بتقنية **React Native + Expo SDK 52** مع دعم كامل للغة العربية (RTL).
   - توثيق ذكي وسريع عبر واتساب (WhatsApp OTP) مجاني 100%.

2. **لوحة التحكم الإدارية (Frontend - Admin):**
   - لوحة تحكم متكاملة لإدارة الخدمات، الشكاوى، الأخبار، والحرفيين.

3. **الخادم الأساسي (Backend - Go API):**
   - معمارية **Modular Monolith** فائقة السرعة بلغة **Go**.
   - إدارة الجلسات وتأمين الـ JWT وصلاحيات الـ RBAC.

4. **بوابة الخدمات (Backend - Python Gateway):**
   - معالجة طلبات التوثيق وربط خدمة الواتساب الآلية عبر Baileys.

## 🔒 الأمان وتوثيق الحسابات
- توثيق فوري بدون كلمات مرور معقدة عبر كود تحقق سري مكون من 4 أرقام يصل المواطن على الواتساب من سيرفر القرية مباشرة.
- ربط بصمة الجهاز لمنع إنشاء حسابات وهمية مكررة.
